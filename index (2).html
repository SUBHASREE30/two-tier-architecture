Verification Evidence

1

DB Security Group — Port 3306 Source = web-sg ID

The database security group inbound rule shows source as sg-xxxxxxxx (web-sg ID) — not an IP address. This proves security group chaining is correctly configured. Only web tier instances can reach the database.

2

Browser Health Check — Database Connection: OK

Accessing http://<WEB_PUBLIC_IP>/dbtest.php in the browser displays the green success message confirming the PHP script successfully connected from the public web server to the private MySQL database.

3

Ping Timeout — Private Subnet Isolation Confirmed

Running "ping 10.0.2.x" from a local machine results in 100% packet loss / timeout. The private subnet has no IGW route, confirming the database is completely unreachable from the internet.
